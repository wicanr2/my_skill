# 復古 remake 戰術固定骨架驗證補充

本檔是 Codex 本機方法補充，不修改 Claude 上游快照。固定骨架畫面要分成
「來源畫布、同狀態、區域契約」三層驗證，不能只看縮小後的並排圖：

1. 記錄原版 framebuffer、模擬器 client 與 remake 邏輯畫布尺寸；先裁掉視窗
   裝飾／黑邊，只用整數最近鄰縮放。影片 `scale`／`pad` 不得反推遊戲座標。
2. 對照固定戰鬥類型、攻守方、地形／城牆、編成、命令、鏡頭、時間步與動畫
   frame。fixture 或不同局面只能標 `layout-only`，不得宣告完整 parity。
3. 把 viewport、狀態欄、縮圖、命令列、按鈕 glyph、TALK、游標逐區記成
   `(x,y,w,h)`，以單一幾何來源驅動繪製、命中測試及回歸測試。
4. 骨架通過後才驗地形投影、物件深度排序、色盤、文字 baseline、動畫相位與
   音效時序。
5. 保存未縮放 PNG、差分圖、座標表與擷取 metadata；先排除成片裁切／縮放偏位，
   才把差異歸因到 remake。
