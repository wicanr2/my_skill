# 推廣影片:配樂用原版、聲紋用第一性原理(鐵則)

> 觸發:做/改/重出推廣影片·trailer·遊戲宣傳片;選或換配樂/音效;比對音色·聲紋·音訊品質。
> 來源教訓:u1-cht(創世紀一代繁中)推廣片 2026-06-28——用自寫 2-op FM 合成器「逼近」FM Towns
> 音樂當配樂,音色完全不對、被使用者評為「不適合人類聽」;而原版其實是 CD-DA 真實錄音、早就抽好在
> `u7-cht/u2-cht/build/music/track*.ogg`。繞了一大圈才用對。

## 鐵則 1 — `[HARD]` 推廣影片配樂必須用「原版實際素材」,不可自產

- **配樂、音效一律取自原版/原作的真實音訊**:原版 CD-DA 音軌、用正確模擬器(Tsugaru/openMSX/MAME 等)
  跑原版錄到的真實晶片輸出、官方 OST。**絕不可用自己寫的合成器/逼近渲染當配樂**。
- 自產的「逼近」(2-op FM、亂湊音色、TTS、AI 生成曲)= 音色錯、廉價、毀掉作品真實感。retro 作品尤其
  ——玩家對原曲有記憶,一聽就知道是假的。
- 同理延伸到**畫面**:用真實實機截圖/錄影,不要用 mockup 或重畫的假畫面充數。
- **Why**:推廣片是作品的門面;素材真實性 = 可信度。自產素材是「看似省事」的捷徑,實際上既不對味又
  砸招牌。原版素材幾乎都已存在(專案先前 RE 抽過),只是要去找,不是去合成。
- **How to apply**:動手配樂前先問「原版的這段音樂/音效在哪?」→ 找已抽出的 CD 音軌/錄音/OST;
  沒有就用模擬器錄原版(有界執行);**真的找不到才回報並請使用者決定,不可自己合成頂替**。

## 鐵則 2 — `[HARD]` 比對音色·聲紋·音訊品質,用第一性原理,不靠記憶

- 不要憑記憶斷言「這個檔就是原版音樂 / 這個音色對」。**每個音訊素材先反追溯源 + 看技術訊號**再用。
- **第一性檢查清單**(用 ffprobe/sox/python 頻譜,不用耳朵猜也能判很多):
  - **怎麼來的(provenance)**:真實錄音 / 模擬器擷取 / 官方檔 → 可信;自寫合成器 / 逼近 → 音色八成錯。
  - **bitrate / 檔案大小 vs 時長**:10KB / 53s 的 ogg ≈ 壞檔或近乎空白;真實 CD-DA 音樂應數百 KB~MB。
  - **聲道 / 取樣率 / 時長**:對不對得上「該是什麼」。
  - **頻譜**:單調方波/三角 = 粗糙合成;豐富泛音 = 真實樂器/錄音。有無 clipping、雜訊、DC offset。
- **Why**:這次就是憑記憶以為 `fmtowns.ogg` 是「FM Towns 音樂」直接用,沒做第一性查證——一查就會發現
  它是 2-op 合成(262KB 但音色錯),而真實 CD 音軌(track03,2.8MB CD-DA)就在隔壁。
- **How to apply**:用任何音訊前,先 `ffprobe` 看時長/bitrate/聲道 + 確認它「怎麼產生的」;判「好不好聽/對不對」
  時做頻譜分析,別下「我記得這個可以」。與 [[62-static-provenance-trace]](反追溯源)、
  [[83-retro-completeness-over-roi]](保全真實)、第一性原理常駐原則同源。

## 但書 — 用原版音樂 ≠ 可任意散布(IP / 著作權)

鐵則 1「配樂用原版」管的是**品質/真實性**;但原版遊戲音樂多半是**他人著作權**(作曲家的旋律),
這跟「能不能放進對外公開的影片」是兩回事,別混為一談。

- **個人保存 / 圓遺憾 / 內部 demo**:用原版音樂沒問題;素材與產出**一律 gitignore 不入庫散布**
  (本來就該如此)。
- **對外公開**(上傳 YouTube / 客戶 / 社群)的推廣片:配上原版著作權音樂 = 散布他人著作 → 風險。
  動手把原版音樂混進「會公開」的影片前,**先提醒使用者這個 IP 面向**,讓他決定(可能改用授權曲、
  原創曲、或自有著作權的版本)。這是「對外/不可逆動作前先確認」的一種(同 agent 邊界)。
- **判準**:影片會不會公開 → 會,就先 flag IP;只在本機保存,就照鐵則 1 用原版、保持 gitignore。
- **Why**:鐵則 1 為了「不要用爛音色砸招牌」;這條為了「不要因為散布著作權音樂惹麻煩」。兩者不衝突 ——
  品質要真、散布要合法,缺一不可。
